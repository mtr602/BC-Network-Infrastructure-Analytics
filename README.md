Spatial and statistical analytics project evaluating internet performance, latency, and infrastructure trends across British Columbia using Ookla Open Data.

## Project Overview

This project analyzes fixed broadband performance across BC using geospatial mapping, KPI benchmarking, and statistical analysis. The objective was to identify how geography and infrastructure influence internet quality across urban, suburban, rural, and remote regions.

## Tools & Technologies

* R
* Python
* SQL
* DuckDB
* Power BI
* GeoPandas
* ggplot2
* Leaflet

## Key Features

* Processed large-scale Ookla Open Data datasets
* Converted quadkeys into geospatial coordinates
* Built BC regional classification workflows
* Created download speed and latency visualizations
* Performed infrastructure and network performance analysis
* Developed KPI benchmarking metrics

## Key Findings

* Urban regions showed the strongest broadband performance
* Rural and remote regions experienced higher latency
* Infrastructure density correlated with stronger network quality
* BC maintained strong overall broadband performance during Q1 2024
